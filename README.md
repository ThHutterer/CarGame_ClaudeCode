# CarGame 🏎️

An exciting HTML5 car racing game built with JavaScript! Avoid obstacles, increase your speed, and try to get the highest score!

## Features

- 🎮 Touch controls optimized for iPhone and mobile devices
- ⌨️ Keyboard controls for desktop (arrow keys)
- 🚗 Smooth car movement and physics
- 🎯 Progressive difficulty - speed increases as you score
- 📱 Responsive design works on all screen sizes
- 🎨 Colorful graphics with multiple obstacle colors

## How to Play

### On iPhone/Mobile:
1. Open `index.html` in Safari or your mobile browser
2. Tap "Start Game"
3. Touch and drag left/right on the screen to steer your car
4. Avoid the colored obstacle cars
5. Your speed increases every 100 points!

### On Desktop:
1. Open `index.html` in any web browser
2. Click "Start Game"
3. Use Arrow Left/Right keys to steer
4. Avoid obstacles and rack up points!

## Installation

Simply open `index.html` in a web browser - no installation or build process needed!

For iPhone, you can:
- Upload to any web hosting service
- Open directly from your device
- Add to home screen for full-screen experience

## Scoring

- Each obstacle you successfully avoid = 10 points
- Speed multiplier increases every 100 points
- Try to beat your high score!

## Technical Details

- Pure HTML5 Canvas for rendering
- Vanilla JavaScript - no dependencies
- Optimized for mobile touch events
- 60 FPS game loop using requestAnimationFrame
